## What shipped in 2.5.0

A persistent **AI memory ("AI brain")**: RCWriter now remembers what its AI did,
decided and suggested across sessions, and feeds the relevant parts back into
later AI work so it stays consistent and learns from what worked.

### Design decisions (confirmed with the owner)
- **Storage:** a single JSON store inside the normal data file (`store.data.aibrain`)
  with keyword × importance × recency ranking — **not** native SQLite/FTS5, to
  avoid native-module build risk in the pure-JS Electron app.
- **What is recorded:** high-signal events only.
- **Recall budget:** ~1,500 tokens.
- **Consolidation:** may use the Assistant AI to distil "lessons".

### Module — `src/aibrain.js`
`createBrain({ store, ai, sessionId, onChange })` returns:
`log, updateOutcome, recall, consolidate, search, edit, remove, forget,
setPaused, exportAll, status, redact, SYSTEM_INSTRUCTION`.

- Entry shape: `{ id, ts, type, summary, details, reasoning, outcome,
  relatedIds, tags, importance, sessionId }`.
- Types: `action, decision, suggestion, user_feedback, fact`.
- Outcomes: `pending, accepted, rejected, succeeded, failed`.
- **Redaction** before writing: API keys (Anthropic/OpenAI/Google/GitHub/Slack),
  bearer tokens, long hex/base64, and secret-named object keys → `[redacted]`.
- **recall()** builds a token-budgeted `## Relevant memory from past sessions`
  block: last 10 from this session + up to 15 past entries ranked by
  keyword match × importance × recency (rejected/failed get a boost so the AI
  avoids repeating them).
- **consolidate()** distils old low-value entries into up to 6 durable `fact`
  "lessons" via the Assistant AI and archives the originals; gated weekly /
  by threshold, or `force`.
- `CAP = 4000` live entries, with `autoArchive()` of old low-importance ones.

### Integration
- `src/audit.js` — `createAuditor({ ..., memory })` injects
  `memory.instruction` + `memory.recall(job)` into the audit/revision system
  prompt (after the per-site memory block).
- `src/assistant.js` — Ask RCWriter injects recall + `SYSTEM_INSTRUCTION`, and
  logs a `suggestion` entry after each answer.
- `src/main.js`:
  - `brain = createBrain({ store, ai: assistantAi, sessionId: brainSession,
    onChange: broadcast })` created before the auditor.
  - `logAuditToBrain(job, rec, text)` records each finished audit/revision/task.
  - `runWriter` logs an `action` when an article is produced.
  - **Approval decisions:** `audit:decide` / `audit:decideAll` snapshot the
    approval **before** `auditor.decide()` (which can remove it), then log a
    `user_feedback` entry (accepted/rejected).
  - `publicState().brain = brain.status()`.
  - Consolidate tick ~60s after launch.
  - IPC: `brain:list / edit / delete / forget / pause / consolidate / export`.
- `src/preload.js` — `brainList / brainEdit / brainDelete / brainForget /
  brainPause / brainConsolidate / brainExport`.

### UI — `src/renderer/aibrain-ui.js`
Workspace → **AI memory**: browse, search by text/type, change importance,
delete, **Pause recording**, **Make lessons**, **Export** to JSON, **Forget all**.
Entries are fetched on demand (not part of app state). Nav item + CSS
(`.mem-*`) + `<script>` tag added; renderer stays un-obfuscated by design.
